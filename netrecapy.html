Topic 01 – Network Hardware & Devices
Question 01
Which of the following is a characteristic of a PASSIVE networking device?
AIt requires its own power supply
BIt only creates a physical connection without changing data
CIt amplifies and regenerates signals
DIt routes packets across networks
Answer: B — Passive devices (e.g., cables, patch panels, connectors) are involved in data transmission but do NOT change or affect the data. They are typically unpowered and simply create a physical connection.
Question 02
A Repeater operates at which layer of the OSI model?
AData Link Layer (Layer 2)
BNetwork Layer (Layer 3)
CPhysical Layer (Layer 1)
DTransport Layer (Layer 4)
Answer: C — A Repeater works at the Physical Layer (Layer 1) of the OSI model. It amplifies and regenerates the incoming signal and requires power to do so.
Question 03
Why are Hubs generally NOT recommended for large networks?
AThey use the wrong cable type
BThey operate only at Layer 3
CThey broadcast traffic to ALL ports causing network slowdown
DThey cannot support Ethernet
Answer: C — Hubs broadcast all traffic to all connected ports. The more devices added, the more network collisions and congestion occur, eventually making the network unusable.
Question 04
What is the key difference between a Switch and a Hub?
AA switch only works with fiber optic cables
BA switch sends traffic only to the intended destination port, not all ports
CA switch operates at Layer 1, a hub operates at Layer 2
DA switch cannot connect multiple devices simultaneously
Answer: B — A switch intelligently forwards frames only to the intended device port using MAC address tables, while a hub broadcasts to all ports. This allows multiple users to communicate simultaneously without slowdown.
Question 05
A Bridge connects two LANs that use:
ACompletely different protocols at all layers
BThe SAME logical link control protocol (may have different MAC protocols)
COnly fiber optic connections
DWAN connections only
Answer: B — A Bridge interconnects two LANs using the SAME logical link control (LLC) protocol but may use different medium access control (MAC) protocols. E.g., Ethernet-to-Ethernet or Ethernet-to-Token Ring.
Question 06
What does a Router use to determine the best path for forwarding packets?
AMAC address table
BARP table only
CRouting table with distance and cost algorithms
DPhysical cable connections only
Answer: C — A router creates and maintains a routing table of available routes and uses distance and cost algorithms to determine the best route for each packet toward its destination.
Question 07
A Gateway is used to interconnect:
ATwo different networks with different protocols/equipment
BTwo identical LANs using the same media
COnly two WAN connections
DOnly wireless to wired networks
Answer: A — A Gateway acts as an entrance to another network and can connect completely different network types. Gateway nodes control traffic between internal networks and external networks/ISPs.
Question 08
Which of the following are active network devices? (Best answer)
APatch panels, coaxial cables, connectors
BFiber optic cables, switchboards
CRepeaters, Hubs, Switches, Bridges, Routers, Gateways, Access Points
DCable trays and ducts
Answer: C — Active devices require their own power supply and actively process network signals. They include Repeaters, Hubs, Switches, Bridges, Routers, Gateways, and Access Points. Passive devices (cables, connectors, patch panels) do NOT require power.
Topic 02 – Network Types
Question 09
Which network type is organized around an individual person within a single building?
ALAN
BPAN
CMAN
DWAN
Answer: B — A Personal Area Network (PAN) is organized around an individual person within a single building. It typically uses Bluetooth, ZigBee, or Wi-Fi and includes phones, laptops, headsets, and game consoles.
Question 10
What is the maximum number of interconnected devices in a typical LAN?
ALess than 100
BLess than 500
CLess than 1000
DLess than 5000
Answer: D — According to the lecture, a LAN consists of less than 5000 interconnected devices across several buildings. It covers limited areas like schools, labs, homes, and office buildings.
Question 11
Which WAN component sits between the router and the WAN connection, converting digital signals?
ADTE (Data Terminal Equipment)
BCSU/DSU (Channel/Data Service Unit)
CDCE (Data Circuit-terminating Equipment)
DAccess Point
Answer: B — CSU/DSU (Channel Service Unit / Data Service Unit) sits between the router and WAN connection, converting digital signals from the WAN into a format the router understands and vice versa.
Question 12
SOHO networks typically consist of which combination?
AMultiple routers, many switches, no wireless
BOne Ethernet switch, one router, one wireless access point
COnly fiber connections and dedicated servers
DMultiple hubs and coaxial cabling
Answer: B — SOHO (Small Office / Home Office) networks serve 1–10 workers and are typically built with one Ethernet switch, one router, and one wireless access point.
Question 13
Which characteristic best describes a Peer-to-Peer (P2P) network?
ACentralized control with dedicated servers
BRequires sophisticated configuration
CDecentralized, self-organizing with no centralized hardware
DRequires extra peripherals and faster processors
Answer: C — P2P networks have no centralized HW or control (decentralized), are self-organizing, easy to implement, low-cost, and have high scalability — but issues with controllability and management.
Question 14
What are the 5 main functions of a Wireless Router in a home network?
ASwitching, Amplifying, DNS, FTP, SSH
BRouting, Switching, Access Point, DNS, Firewall (packet filtering)
CBridging, Repeating, NAT, DHCP, SMTP
DRouting, NTP, SSH, FTP, DNS
Answer: B — A Wireless Router in a home network performs 5 main functions: Routing, Switching, Access Point functionality, DNS, and can also be configured for packet filtering (Firewall). It's called the "Magic Device".
Question 15
Which technology is primarily used for last-mile internet connectivity in home networks?
AToken Ring
BFiber/Microwave (FTTH, 4G/5G) and DSL/Cellular
CCoaxial Ethernet only
DSatellite only
Answer: B — Last-mile connectivity for home networks uses Fiber/Microwave (FTTH, 4G/5G) or DSL/Cellular. ADSL (Asymmetric Digital Subscriber Line) is also used for home internet connections.
Question 16
A Campus Network differs from a simple LAN because it:
ASpans several buildings with high intranet data volumes and multiple network services
BUses only wireless connections
CConnects directly to the internet without a router
DIs limited to a single floor of a building
Answer: A — A Campus Network spreads over several buildings with many network services, high intranet data volumes, different user types, more covering area with open space, and may connect external branch networks.
Question 17
Which technologies are used in WAN connectivity?
ABluetooth, ZigBee, Wi-Fi
BPatch panels, switchboards
CLeased lines (Metro Ethernet T1/T3), WiMAX, DSL
DOnly satellite connections
Answer: C — WAN technologies include: Leased lines (Metro Ethernet - Fiber, T1/T3/E1/E3), Wireless Connections (WiMAX), and Shared networks (DSL). WANs cover large geographical areas connecting multiple LANs.
Question 18
What is a key LIMITATION of a SOHO network?
ANo guaranteed connection and no permanent IP address block
BCannot use wireless connections
CRequires leased lines only
DCannot connect more than 2 devices
Answer: A — SOHO networks have two key limitations: No guaranteed internet connection (dynamic/shared), and No permanent IP address block (no static public IP block assigned by ISP).
Topic 03 – Transmission Media
Question 19
What is the formula for calculating Data Rate from Bandwidth?
AData Rate = Bandwidth × 8
BData Rate = Bandwidth / 8
CData Rate = Bandwidth × 1024
DData Rate = Bandwidth / 1000
Answer: B — Data rate is measured in Bytes. Since 1 Byte = 8 bits, Data Rate = Bandwidth / 8. Example: 100 Mbps bandwidth = 12.5 MBps data rate (100,000,000 / 8).
Question 20
Coaxial cable can transmit signals over how far with low attenuation?
A100m
B200m
C500m
D1000m
Answer: C — Coaxial cable can transmit signals over 500m with low attenuation. It can transmit over longer distances using repeaters. It was first used in 1850s and is used for cable TV, telephone, and LAN.
Question 21
Which twisted pair category supports 1000 Mbps (Gigabit Ethernet)?
ACAT 3
BCAT 4
CCAT 5
DCAT 5e/6
Answer: D — CAT 5e/6 supports 1000 Mbps (Gigabit Ethernet) and is used for LAN, CCTV, and data communication. CAT 5 only supports 100 Mbps, CAT 3 supports 16 Mbps.
Question 22
Why are wires TWISTED in twisted pair cables?
ATo increase signal strength
BTo reduce cross-talk (electromagnetic interference)
CTo save manufacturing costs
DTo increase the cable's flexibility
Answer: B — The wires in twisted pair cables are twisted together specifically to reduce cross-talk (electromagnetic interference between adjacent wires). Each pair has a different twist rate to minimize interference.
Question 23
What is the core diameter range of optical fiber?
A2 to 125 micrometers (µm)
B1 to 10 millimeters (mm)
C50 to 500 micrometers
D1 to 5 centimeters
Answer: A — Optical fiber has a glass or plastic core of 2 to 125 µm (micrometers). The core is surrounded by cladding (insulating) and a jacket (protective cover). Light is transmitted via laser or LED.
Question 24
What is the difference between Multimode and Single Mode optical fiber?
AMultimode is used for longer distances; single mode for shorter
BMultimode carries multiple light rays simultaneously; single mode carries one ray for longer distances
CSingle mode is cheaper; multimode is more expensive
DThey are identical except for the cable color
Answer: B — Multimode fiber carries multiple light rays at slightly different reflection angles. Single mode (monomode) uses a single ray as a carrier and is used for LONGER distances due to less dispersion.
Question 25
Which is a key advantage of optical fiber over copper cables?
ALower cost
BEasier to splice and connect
CElectromagnetic isolation (immune to external EM interference)
DCan carry electrical power
Answer: C — Optical fiber provides electromagnetic isolation — it is not affected by external electromagnetic environments, providing more privacy and security. Other advantages: lower attenuation, greater capacity (2 Gb/s), smaller/lighter, greater repeater spacing.
Question 26
Which category of Guided Medium is used for long-distance telecommunication with 2 Gb/s capacity?
ACoaxial Cable
BUTP Cable
COptical Fiber
DSTP Cable
Answer: C — Optical Fiber supports 2 Gb/s over tens of kilometers and is used for long-distance telecommunication. It has lower attenuation, smaller size, lighter weight, and greater repeater spacing than copper cables.
Question 27
CAT 1 twisted pair cable is primarily used for:
AAnalog voice (plain old telephone service) and doorbell wiring
BGigabit Ethernet
CToken Ring networks at 4 Mbps
DServer room connections
Answer: A — CAT 1 supports less than 1 Mbps and is used for analog voice (POTS - Plain Old Telephone Service), ISDN Basic Rate Interface, and doorbell wiring. Not suitable for data networks.
Question 28
What are the THREE layers/components of an optical fiber cable?
ACopper, Insulator, Jacket
BCore (glass/plastic), Cladding (insulating), Jacket (protective)
CShield, Copper, PVC wrap
DCore, Mesh, Sheath
Answer: B — Optical fiber structure: (1) Core — glass or plastic, 2–125 µm diameter; (2) Cladding — insulating material surrounding the core; (3) Jacket — protective outer cover. Light travels through the core via total internal reflection.

AGuglielmo Marconi
BJames Clerk Maxwell

Answer: B — In 1873, Maxwell proposed the idea of using electromagnetic waves to propagate message signals. Marconi later invented the wireless Telegraph in 1896 and the first wireless message "Are you ready?" was sent across 6km in 1897.

AIEEE 802.11
BIEEE 802.3
CIEEE 802.15.1
DIEEE 802.16
Answer: C — Bluetooth follows IEEE 802.15.1 specification. It's a high-speed, low-powered wireless technology designed to connect portable equipment. IEEE 802.11 is Wi-Fi, 802.3 is Ethernet, 802.16 is WiMAX.
Question 31
What is the frequency range used by Radio Frequency (RF) signals?
A1 Hz to 1 kHz
B3 kHz to 300 GHz
C300 MHz to 300 GHz only
D100 GHz to 1 THz
Answer: B — RF signals range from 3 kHz to 300 GHz. They are used in wireless communication because they can penetrate through objects and travel long distances. Microwave is specifically 300 MHz to 300 GHz.
Question 32

A6,000 miles
B12,000 miles (low orbit)
C22,000–22,300 miles

Answer: C — Geostationary satellites orbit at approximately 22,000–22,300 miles above Earth. Low orbit satellites orbit at 12,000 miles. Geostationary orbit allows the satellite to appear stationary relative to Earth's surface.
Question 33
What is the key requirement for Terrestrial Microwave Transmission (TMTS)?
AUnderwater cables
BSatellite relay stations
CLine-of-sight communication between towers
DOmnidirectional antennas only
Answer: C — TMTS requires line-of-sight (LOS) communication between pairs of Earth-based transmitters and receivers. Signals are highly concentrated and relay towers are used for extension. Uses directional parabolic antennas at 4-23 GHz.

BAir

BFunctionality, Adaptability, Scalability, Manageability, Cost-Effectiveness

Topic 01 – Network Hardware
Differentiate between Active and Passive network devices. Give three examples of each and explain their functions in a network.
★★★ High Importance10 Marks
▾
✦ Model Answer

Passive Devices: Passive networking hardware are components involved in data transmission that do NOT change or affect the data. They are typically unpowered and only create a physical connection.

  • Cables (Fiber Optic/Coaxial/Twisted Pair) — Physical medium for signal transmission
  • Connectors (RJ45) — Physical interface between cable and device
  • Patch Panels/Switchboards — Terminate and organize cable connections in equipment rooms

Active Devices: Active network devices require their own power supply. They amplify, process, and clean network signals before forwarding them.

  • Repeater — Amplifies/regenerates signals at Physical Layer (Layer 1). Used as Wi-Fi extenders
  • Switch — Directs frames to specific ports using MAC address tables. Allows multiple simultaneous communications
  • Router — Routes packets between different networks using routing tables and cost algorithms (Layer 3)
  • Hub — Broadcasts all traffic to all ports (less efficient than switches)
  • Bridge — Connects two LANs using same LLC protocol
  • Gateway — Connects different types of networks
Active = needs power Passive = no power Repeater = Layer 1 Switch = Layer 2 Router = Layer 3
Compare and contrast Bridge, Router, and Gateway. In what scenario would you use each device?
★★★ High Importance12 Marks
▾
✦ Model Answer

Bridge: A device that interconnects two LANs using the SAME logical link control (LLC) protocol but may use different medium access control (MAC) protocols.

  • Examines each message on a LAN, passes those within the same LAN, forwards those to other LANs
  • Use case: Connecting two Ethernet segments (e.g., extending a LAN to a new floor)

Router: A device that determines the next network point to which a packet should be forwarded toward its destination. Connects SIMILAR networks (similar protocols).

  • Creates and maintains a routing table of available routes with distance/cost algorithms
  • A packet travels through many routers before reaching its destination
  • Use case: Connecting your office LAN to the internet or connecting multiple branch offices

Gateway: A network point acting as an entrance to another network. Connects two DIFFERENT networks with different protocols/equipment.

  • Controls traffic within a company's network or at an ISP
  • Use case: Connecting a corporate network to a different network protocol system or ISP connection point
Key distinction: Bridge = same LLC protocol | Router = similar networks | Gateway = different networks
Explain the differences between a Hub and a Switch. Why are hubs not recommended for modern networks?
★★ Medium8 Marks
▾
✦ Model Answer

Hub:

  • A place where data converges from one or more directions and is forwarded out in ALL directions
  • Broadcasts all traffic to ALL ports regardless of destination
  • As more devices are added, the network becomes slower (collisions increase)
  • All devices share the same bandwidth — inefficient

Switch:

  • Allows different nodes of a network to communicate DIRECTLY with each other (point-to-point)
  • Uses MAC address tables to forward frames ONLY to the intended destination port
  • Allows SEVERAL users to send information simultaneously without slowing each other down
  • Provides dedicated bandwidth per port

Why hubs fail in modern networks: Hubs cannot support large networks because they broadcast traffic to all devices, creating collisions and congestion. More devices = slower network, eventually becoming unusable.

Topic 03 – Transmission Media
Compare Coaxial Cable, Twisted Pair Cable, and Optical Fiber as transmission media. Discuss their construction, advantages, disadvantages, and typical applications.
★★★ High Importance20 Marks
▾
✦ Model Answer

1. Coaxial Cable

  • Construction: Inner solid copper core → insulating material → outer braided shield (ground) → outer sheath. Used since 1850s, theory by Oliver Heaviside.
  • Advantages: Transmits 500m with low attenuation; can carry high-frequency signals; used for cable TV
  • Disadvantages: Bulky and heavy; half duplex; low efficient for complex networks
  • Applications: Cable TV distribution, long-distance telephone, LANs

2. Twisted Pair Cable (UTP/STP)

  • Construction: Pairs of insulated copper wires twisted together (to reduce cross-talk). Unshielded (UTP) or Shielded (STP)
  • Categories: CAT 3 (16 Mbps) → CAT 5 (100 Mbps) → CAT 5e/6 (1000 Mbps) → CAT 6a/7/8 (10–40 Gbps)
  • Advantages: Most economical, widely used for Ethernet and telephone
  • Disadvantages: Limited in distance, bandwidth, data rate

3. Optical Fiber

  • Construction: Glass/plastic core (2–125 µm) + cladding + jacket. Light source: laser or LED. Multimode (multiple rays) or Single mode (one ray, longer distances)
  • Advantages: 2 Gb/s over tens of km; electromagnetic isolation; lower attenuation; greater repeater spacing; smaller/lighter
  • Applications: Long-distance telecom, backbone connections
Data Rate = Bandwidth / 8  |  100 Mbps → 12.5 MBps

Compare Satellite Microwave Transmission (SMTS) and Terrestrial Microwave Transmission (TMTS). What are the advantages and limitations of each?
★★★ High Importance15 Marks
▾
✦ Model Answer

Satellite Microwave Transmission (SMTS):

  • Self-contained wireless technology; worldwide coverage
  • Signal (modulated microwave beam) sent to satellite → amplified → returned to receiver on Earth
  • Geostationary orbit: 22,000–22,300 miles above Earth
  • Two components: Space segment (satellite) + Ground segment (fixed/mobile equipment)
  • Receives on one frequency (uplink), transmits on another (downlink) — Full duplex
  • Applications: TV distribution, long-distance telephone, private business networks
  • Limitations: Very difficult to repair; greater signal delay; attenuation issues; mostly one-directional for broadcast; limited to ~90 satellites in GEO

Terrestrial Microwave Transmission (TMTS):

  • Uses line-of-sight (LOS) communication between Earth-based transmitters/receivers
  • Signals are highly concentrated; must have clear LOS path
  • Extended using Relay towers (<60 miles between towers preferred)
  • Uses directional parabolic antennas at 4–23 GHz frequency
  • Speed: 1 Mbps to 10 Mbps
  • Advantages: Less expensive than fiber/coaxial; fewer amplifiers/repeaters; low latency (IP microwave)

Topic 07–08 – Structured Cabling
Describe the Six Elements of Structured Cabling as defined by TIA/EIA-568. Explain the role of each element.
★★★ High Importance15 Marks
▾
✦ Model Answer

The Six Elements of Structured Cabling (TIA/EIA-568):

  • 1. Building Entrance Facility: Where outside cabling/services interface with backbone cabling. (Electrical equivalent: meter panel with main circuit breaker). Requirements: dry area, clear pathways, easy access for service persons, space for expansion.
  • 2. Equipment Room (ER): Where incoming cabling interfaces with electronic equipment. Main Cross-Connect (MC) to backbone. (Electrical equivalent: Main Distribution Panel). Must be: minimum 14m², secured, proper HVAC, close to backbone, proper grounding (<5Ω).
  • 3. Building Backbone Cabling: Connects different floors and different buildings (vertical/inter-building cabling). The highway of the structured cabling system.
  • 4. Horizontal Cabling: Pathway and cabling between the Telecom Room and Work Area. Like streets connecting backbone highways to individual offices.
  • 5. Telecommunications Closet (TC): Space acting as common access point between backbone and horizontal cabling. Houses patch panels for cross-connection. (Electrical equivalent: circuit breaker panel/distribution board). Horizontal cable max: 90m. Multiple TCs needed if floor >1000m².
  • 6. Work Area: Where PCs, phones, printers are located. Includes equipment cords. General rule: 1 WA = 10 m². Sufficient outlets must be placed based on application.
Explain the TIA/EIA 568A and 568B standards. What is the practical difference between straight-through and crossover cables?
★★ Medium10 Marks
▾
✦ Model Answer

TIA/EIA 568A vs 568B:

  • Both standards describe the order of wires in the RJ45 connector
  • Functionally IDENTICAL — no performance difference
  • Only difference: positions of Green and Orange wires are switched
  • Sri Lanka uses 568-B standard

Straight-Through Cable (568B on both ends):

  • Used to connect intermediate devices with end devices
  • Example: PC to Switch, PC to Router, Switch to Router
  • In 100BaseT: uses Pins 1,2 (TX) and 3,6 (RX)

Crossover Cable (568A on one end, 568B on other):

  • Used to connect two END devices directly
  • Example: PC to PC, Switch to Switch, Hub to Hub
  • TX pins connect to RX pins of the other device

PoE (Power over Ethernet): In 100BaseT, pins 4,5,7,8 are unused for data and can carry power for CCTV cameras and Access Points. Requires PoE switches.

Gigabit Ethernet (1000BaseT): Uses ALL 4 pairs (pins 1-8) for data. Requires CAT 5e/6/7 cables. Maximum distance: 100m.
